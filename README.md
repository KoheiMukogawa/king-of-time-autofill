# KING OF TIME 月間スケジュール申請ヘルパー

勤務予定の月間申請を、ブラウザ上で半自動的に入力するツールです。有志で作って共有しているもので、
会社の公式ツールではありません。

## これは何をするか

- 月のシフトを1回入力すると、出勤日と休日をまとめてプレビューできます
- 休日の一括フォーム入力を補助します
- 出勤日の勤務時間を、日別フォームへ自動で入力します
- 申請済みの内容を月単位で取り消す作業を補助します

## これは何をしないか

- **初期状態では、申請を自動で送信しません。** 自動で申請する機能は設定でONにするまでボタンすら出ません
- 会社のシステムに何かをインストールしたり、設定を変更したりしません
- 入力した内容は自分のブラウザの中だけに保存されます。どこにも送信しません

## 導入（4ステップ）

1. Chrome ウェブストアで **Tampermonkey** をインストールする
   → https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo
2. `chrome://extensions` を開き、Tampermonkey の「詳細」→
   **「ユーザー スクリプトを許可する」をONにする**
   **これを飛ばすと、あとの手順を全部やっても何も起きません**（エラーも出ません）
3. 次のリンクを開く
   → https://raw.githubusercontent.com/KoheiMukogawa/king-of-time-autofill/main/KING_OF_TIME_Holiday_MVP.user.js
4. 表示された画面で「インストール」を押す

手順2の画面の場所は [docs/INSTALL.md](docs/INSTALL.md) に詳しく書いてあります。

うまくいかないときは [docs/INSTALL.md](docs/INSTALL.md) に詳しい手順があります。

## 休憩時間について

休憩は申請しません。勤務時間を入力するとき、休憩欄は空にします。
シフト制で休憩がない日や時刻がばらばらの日があり、休憩は打刻時に KING OF TIME が
自動で付けるためです。申請に休憩を入れたい日は、日別の入力後に申請画面で自分で入力してください
（連続申請では休憩欄が空のまま送信されます）。

## 連続申請について

「連続申請（自動で実際に申請する）を使う」は、最初はOFFになっています。
手動での入力を何度か試して、内容が正しいことを自分の目で確認してから
パネル上部の「設定」でONにして「設定を保存」を押してください。

## うまく動かないとき

パネルのタイトルに表示されているバージョン（例: `v0.7.0`）と、
画面に出ているメッセージを添えて連絡してください。

## 更新について

修正すると Tampermonkey が自動で新しい版を取ってきますが、確認のタイミングは
Tampermonkey まかせで、すぐには反映されないことがあります。不具合を報告してくれた人には、
まず Tampermonkey のダッシュボードで「更新を確認」を押してもらい、最新版になっているか
確かめてから試してもらってください。手動で更新したいときも同じ操作です。

以前のバージョンを使っていた人へ：「出勤日の時間を連続申請」ボタンは既定でOFF（非表示）に
なりました。使いたい場合は「設定」の「連続申請（自動で実際に申請する）を使う」を
あらためてONにしてください。

## 開発者向け：リリース手順

1. `KING_OF_TIME_Holiday_MVP.user.js` を修正する
2. **`// @version` と `const SCRIPT_VERSION` の両方を上げる**（片方だけだとテストが落ちます）
3. `node KING_OF_TIME_Holiday_MVP.test.cjs` が通ることを確認する
4. `main` に push する

**`@version` を上げないと、修正は誰にも届きません。** Tampermonkey は
バージョン番号が上がったときだけ更新します。
